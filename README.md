# Travel Helper — сайт на Python

Сайт содержит:

- калькулятор валют;
- переводчик текста;
- красивый адаптивный дизайн для компьютера и телефона.

## Как запустить

1. Установите Python 3.
2. Откройте терминал в папке проекта.
3. Установите библиотеки:

```bash
pip install -r requirements.txt
```

4. Запустите сайт:

```bash
python app.py
```

5. Откройте в браузере адрес:

```text
http://127.0.0.1:5000
```

Для перевода и получения курсов валют требуется интернет.

## Структура

- `app.py` — серверная часть на Flask;
- `templates/index.html` — страница сайта;
- `static/style.css` — оформление;
- `static/script.js` — кнопки и запросы к серверу.


## Публикация на Render

Проект уже подготовлен для Render. В нём есть `render.yaml` и `gunicorn`.

1. Загрузите все файлы проекта в GitHub-репозиторий.
2. На Render выберите **New → Blueprint**.
3. Подключите репозиторий.
4. Нажмите **Deploy Blueprint**.
5. После сборки сайт получит адрес вида `https://travel-helper.onrender.com`.

Если имя `travel-helper` занято, Render предложит другое уникальное имя.
